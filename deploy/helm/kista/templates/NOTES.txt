kista {{ include "kista.version" . }}, release {{ .Release.Name }} in {{ .Release.Namespace }}.

Wait for the pods to be ready:
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "kista.fullname" . }}

The first administration, in a pod (the image has no shell; kubectl exec runs kista directly):
  alias ka='kubectl -n {{ .Release.Namespace }} exec -i deploy/{{ include "kista.fullname" . }} -- /kista admin -config /etc/kista/kista.yaml'
  ka migrate
  ka tenant create acme
  ka channel create acme/prod -kind signed

Anyone who may exec into these pods, create Jobs or read Secrets in this namespace acts as kista's
server administrator: the namespace's RBAC is the boundary.
